# Authoritative Metric Definitions and Mathematical Formulations

This document formalizes the canonical evaluation definitions and mathematical guarantees used uniformly across all baselines (B1–B6) in the Indian PII Robustness Benchmark.

## 1. Core Sets and Primitives

Let $D$ be the benchmark corpus consisting of $N = 964$ records. For each record $r \in D$, let:
- $G_r = \{(s_i, e_i, t_i)\}$ be the set of gold standard PII entities, where $s_i$ is the 0-indexed start character offset, $e_i$ is the end character offset (exclusive), and $t_i \in \mathcal{T}$ is the PII entity type.
- $P_r = \{(\hat{s}_j, \hat{e}_j, \hat{t}_j)\}$ be the set of predicted entities generated by the model.
- Total gold entities: $N_{gold} = \sum_{r \in D} |G_r| = 724$.
- Total predicted entities: $N_{pred} = \sum_{r \in D} |P_r|$.

Entity types $\mathcal{T}$ comprise 9 Indian PII categories: `NAME`, `PHONE`, `EMAIL`, `AADHAAR`, `PAN`, `PASSPORT`, `VOTER_ID`, `DRIVING_LICENSE`, and `UPI_ID`.

## 2. Match Classifications

For each record, bipartite matching is performed between gold entities $g \in G_r$ and predicted entities $p \in P_r$:

1. **Exact Match ($TP_{exact}$)**:
   $$\hat{s}_j = s_i \quad \land \quad \hat{e}_j = e_i \quad \land \quad \hat{t}_j = t_i$$
   The prediction exactly matches the gold start offset, end offset, and entity type.

2. **Type-Strict Match ($TP_{type}$)**:
   $$\hat{t}_j = t_i \quad \land \quad \max(s_i, \hat{s}_j) < \min(e_i, \hat{e}_j)$$
   The prediction has the correct entity type and has non-zero character overlap with the gold span. By construction: $TP_{type} = TP_{exact} + F_2$.

3. **Error Partitions**:
   - **$F_1$ Missed (False Negative)**: A gold entity $g \in G_r$ with zero character overlap with any prediction in $P_r$.
   - **$F_2$ Wrong Span (Boundary Error)**: A gold entity $g \in G_r$ that overlaps with a prediction having $\hat{t}_j = t_i$, but where $(\hat{s}_j, \hat{e}_j) \neq (s_i, e_i)$.
   - **$F_3$ Wrong Type (Classification Error)**: A gold entity $g \in G_r$ that overlaps with a prediction where $\hat{t}_j \neq t_i$.
   - **$F_4$ False Positive**: A predicted entity $p \in P_r$ that has zero overlap with any gold entity, or excess spurious predictions over the matched gold entity.

## 3. Mathematical Invariants

The benchmark guarantees the following mathematical identity for every baseline and seed:

$$TP_{exact} + F_1 + F_2 + F_3 = N_{gold} = 724$$

$$TP_{type} = TP_{exact} + F_2$$

$$N_{pred} = TP_{type} + F_3 + F_4$$

## 4. Formal Metric Definitions

1. **M1 Precision (Type-Strict)**:
   $$M_1 = \frac{TP_{type}}{N_{pred}} = \frac{TP_{type}}{TP_{type} + F_3 + F_4}$$

2. **M2 Recall (Type-Strict)**:
   $$M_2 = \frac{TP_{type}}{N_{gold}} = \frac{TP_{type}}{TP_{exact} + F_1 + F_2 + F_3}$$

3. **M3 F1 Score (Type-Strict)**:
   $$M_3 = \frac{2 \cdot M_1 \cdot M_2}{M_1 + M_2} = \frac{2 \cdot TP_{type}}{N_{pred} + N_{gold}}$$

4. **M4 Exact F1 Score**:
   $$P_{exact} = \frac{TP_{exact}}{N_{pred}}, \quad R_{exact} = \frac{TP_{exact}}{N_{gold}}$$
   $$M_4 = \frac{2 \cdot P_{exact} \cdot R_{exact}}{P_{exact} + R_{exact}} = \frac{2 \cdot TP_{exact}}{N_{pred} + N_{gold}}$$

5. **M5 Type Accuracy**:
   $$M_5 = \frac{TP_{type}}{TP_{type} + F_3} = \frac{TP_{type}}{\text{Localized Predictions}}$$

6. **M6 False Positive Rate (Entity-level)**:
   $$M_6 = \frac{F_4}{N_{pred}}$$

7. **Hard-Negative Record-Level Decoy FPR**:
   $$FPR_{HN} = \frac{\sum_{r \in D_{HN}} \mathbb{I}(|P_r| > 0)}{|D_{HN}|}$$
   where $D_{HN}$ is the set of 50 pure hard-negative records containing no genuine PII.
